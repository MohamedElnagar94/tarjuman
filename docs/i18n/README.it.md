## Cosa fa

Incolla un link di YouTube, carica un video dal tuo computer o dagli un link da quasi qualsiasi sito.

- **Sottotitoli sincronizzati.** I sottotitoli in arabo compaiono sul video riga per riga, con la lingua originale sotto, se vuoi. I sottotitoli generati automaticamente vengono ricomposti in frasi complete prima della traduzione. Se non hanno alcuna punteggiatura, vengono divisi dove chi parla fa davvero una pausa, grazie ai tempi parola per parola di YouTube.
- **Doppiaggio dal vivo che suona umano.** Una voce araba neurale pronuncia ogni frase a tempo con chi parla, in arabo egiziano, saudita, emiratino, siriano, giordano, libanese, marocchino o iracheno. Nessuna frase viene troncata o saltata. Con chi parla velocemente, il video rallenta leggermente mentre la voce recupera, invece di far correre la voce; se rallenti tu il video, la voce ottiene quel tempo in più. Le parole che si scrivono allo stesso modo ma si leggono in modo diverso vengono pronunciate secondo il senso della frase (الجُمَل «le frasi», non الجَمَل «il cammello»), in base all'originale inglese.
- **MP4 doppiato.** Esporta il video con la voce fuori campo in arabo. Può rimuovere la voce di chi parla nell'originale mantenendo musica ed effetti, assegnare a ogni persona una voce maschile o femminile adatta e incorporare o imprimere i sottotitoli.
- **Niente sottotitoli? Nessun problema.** Whisper trascrive l'audio sul tuo computer, poi la trascrizione viene tradotta.
- **File di sottotitoli.** Scarica SRT, VTT o testo semplice, in arabo o bilingue, oppure un MP4 sottotitolato pronto da condividere.
- **Playlist intere.** Dagli il link di una playlist o di un canale per creare sottotitoli, video sottotitolati o video doppiati per ogni video contenuto.
- **Chiedi al video** (IA facoltativa). Ottieni un riassunto, i punti chiave, capitoli cliccabili e risposte che saltano al momento in cui il video tratta la tua domanda. Funziona con Claude o con qualsiasi provider compatibile con OpenAI (Gemini, Groq, OpenRouter, Ollama).
- **Impara l'inglese.** Tocca una parola per vederne il significato, salvala con la sua frase, ripassala più tardi ed esportala in Anki. Puoi anche ripetere una frase, mettere in pausa dopo ogni riga o sfocare i sottotitoli per metterti alla prova.
- **Estensione per il browser.** Usa gli stessi sottotitoli e lo stesso doppiaggio direttamente su YouTube, sui siti il cui player ha i sottotitoli (Coursera, Udemy e altri), sui siti di film e anime che incorporano il player da un altro sito o su qualsiasi altro sito ascoltando l'audio della scheda.
- **Sul telefono.** Apri l'app da qualsiasi telefono connesso alla stessa rete Wi-Fi.

Funzionano anche altre lingue: francese, spagnolo, tedesco, turco e inglese sono integrate come lingue di destinazione.

## Avvio rapido

### Programma di installazione per Windows

Scarica `Tarjuman-Setup-<version>.exe` dalla pagina [Releases](https://github.com/MohamedElnagar94/tarjuman/releases) ed eseguilo. Include il proprio Python, tutti i pacchetti, l'app web e l'estensione per il browser, quindi non ti servono né Python né Node.js. Chiede i diritti di amministratore una sola volta, si installa in Program Files e non tocca il firewall. Tarjuman si apre poi in una finestra propria, come qualsiasi app desktop, senza finestra della console e senza scheda del browser; chiudendo la finestra l'app si arresta. (La finestra è Microsoft Edge in modalità app, presente in ogni Windows 10 e 11; non viene installato nient'altro.)

- Se l'installazione si interrompe subito con "unable to create the directory ...\Temp\is-*.tmp, access is denied", il file del programma di installazione si trova in una cartella contrassegnata a bassa integrità (alcuni strumenti di sandboxing contrassegnano così le loro cartelle di lavoro; `icacls <file>` mostra allora `Low Mandatory Level`). Windows esegue un file del genere con meno diritti. Copialo in un'altra cartella, ad esempio Download, ed esegui la copia.
- Il programma di installazione non è ancora firmato digitalmente, quindi Windows SmartScreen può segnalare un "autore sconosciuto": scegli *Ulteriori informazioni → Esegui comunque*.
- Il primo avvio scarica in background la voce araba offline (circa 60 MB). Il modello Whisper si scarica da solo la prima volta che un video ne ha bisogno.
- I tuoi video, sottotitoli, impostazioni e il file `.env` sono conservati in `%LOCALAPPDATA%\Tarjuman`, separati dal programma. Un aggiornamento li mantiene; la disinstallazione chiede se eliminarli.
- Il menu Start ha un collegamento alla cartella dell'estensione, da usare con *Carica estensione non pacchettizzata* in `chrome://extensions`.

Qualcosa non funziona? Consulta la [Risoluzione dei problemi](../troubleshooting.md). Le novità di ogni versione sono nel [Changelog](../../CHANGELOG.md).

### Dal codice sorgente

Ti servono **Python 3.11+** e **Node.js 20+**.

**Windows:** fai doppio clic su `start.cmd`. Se Windows chiede se eseguire uno script di un autore sconosciuto, crea una volta sola un collegamento sul desktop con `powershell -ExecutionPolicy Bypass -File scripts/create-shortcut.ps1` e avvia Tarjuman da lì: esegue lo stesso script tramite il `cmd.exe` di Windows, quindi la richiesta non compare.

**macOS / Linux:**

```sh
./start.sh
```

Su Debian, Ubuntu e Kali, installa prima `python3-venv` se manca (`sudo apt install python3-venv`).

Il primo avvio installa tutto: i pacchetti Python, la voce araba offline e una build dell'app web. Poi l'app si apre su `http://127.0.0.1:4318`. Agli avvii successivi parte in un paio di secondi. Per usarla dal telefono, apri l'indirizzo che mostra per la tua rete Wi-Fi. Su Windows, se il telefono non riesce a raggiungerla, esegui una volta `scripts/allow-phone.ps1` come amministratore: imposta la rete Wi-Fi di casa come privata e apre le porte di Tarjuman solo sulle reti private.

### Comandi

| Comando | Cosa fa |
|---|---|
| `python -m tarjuman` | Avvia l'app (`--port`, `--host 127.0.0.1` solo per questo computer, `--no-open`) |
| `python -m tarjuman app` | Avvia l'app in una finestra propria (Edge o Chrome in modalità app) invece che in una scheda del browser; chiudendo la finestra l'app si arresta |
| `python -m tarjuman subs <link>` | Scrive i file di sottotitoli in `data/output` (`--lang`, `--format srt,vtt,txt`) |
| `python -m tarjuman setup` | Installa o ripara tutto |
| `python -m tarjuman update` | Aggiorna yt-dlp e il client delle voci, se i download o le voci smettono di funzionare |
| `python -m tarjuman doctor` | Controlla ogni componente |

## L'estensione per il browser

<p align="center">
  <img src="../screenshots/extension-popup.png" alt="Il popup dell'estensione Tarjuman" width="320">
</p>

Installala direttamente dal [Chrome Web Store](https://chromewebstore.google.com/detail/gcfnomfbpenbhdebopmpdfamlaiodflp), oppure compilala dai sorgenti con questi passaggi:

1. Compilala una volta: `npm --prefix extension install && npm --prefix extension run build`.
2. Apri `chrome://extensions` (o `edge://extensions`), attiva la **Modalità sviluppatore**, fai clic su **Carica estensione non pacchettizzata** e scegli `extension/dist`.
3. Lascia l'app in esecuzione, apri un video e fai clic sull'icona di Tarjuman, oppure premi <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd>.

L'estensione comunica solo con l'app sul tuo computer. Il suo kit per il Chrome Web Store (testo della scheda, motivazioni delle autorizzazioni, informativa sulla privacy, immagini promozionali) si trova in [`extension/store`](../../extension/store).

## Come il doppiaggio resta sincronizzato

Le righe dei sottotitoli vengono unite in frasi complete e gli intercalari vengono eliminati. La velocità di ogni frase viene poi scelta in base a una finestra di anticipo di circa 12 secondi, così una frase con margine presta tempo a una più fitta e la velocità cambia gradualmente invece di saltare. Prima che il browser riproduca le prime frasi di ogni tratto, il server le sintetizza e le misura, quindi il piano si basa su durate reali e non su stime, e intanto prepara il tratto successivo in background. Se il doppiaggio resta comunque indietro, il video rallenta all'85% della tua velocità finché la voce non recupera, e va in pausa solo quando il ritardo supera circa due secondi. Il ritmo segue la tua velocità di riproduzione. Spostandoti in qualsiasi punto, il doppiaggio riprende esattamente da lì. Quando i traduttori gratuiti limitano le richieste, un secondo endpoint di Google e poi la traduzione di YouTube stessa mantengono il doppiaggio attivo.

Il progetto completo è descritto in [docs/implementation.md](../implementation.md).

## Privacy

Tarjuman è pensato per funzionare in locale. I tuoi video, sottotitoli, parole salvate, impostazioni e chiave API restano nella cartella `data/` del tuo computer. L'app contatta YouTube (sottotitoli e download), Google Translate e MyMemory (traduzione), il servizio vocale Edge di Microsoft (sintesi vocale) e, solo se lo attivi, il provider di IA che scegli. Niente account, statistiche o tracciamento. Video e audio non vengono mai caricati online.

| Funzione | Cosa esce dal tuo computer | Inviato a | Senza inviare nulla |
|---|---|---|---|
| Sottotitoli di YouTube | Il link del video | YouTube | Carica un file; viene trascritto in locale |
| Traduzione | Le frasi del video, come testo | Google Translate, poi MyMemory | Ancora nessuna alternativa; le frasi salvate funzionano comunque offline |
| Voce del doppiaggio | Ogni frase tradotta e il nome della voce | Le voci di Microsoft Edge, poi Google | Piper, la voce araba locale |
| Download del video | Una richiesta del video | Il sito che lo ospita | Un file già presente sul tuo computer |
| IA (facoltativa, disattivata per impostazione predefinita) | Il testo del video e la tua domanda | Il provider che hai scelto | Lasciala disattivata, oppure usa un server locale come Ollama |
| Download dei modelli | Una richiesta di download, una sola volta | Hugging Face, GitHub | Nulla dopo il primo download |
| Riconoscimento vocale, separazione della musica, i tuoi file | Nulla | – | Sempre in locale |

La stessa tabella si trova nell'app, in Impostazioni → Privacy. L'API rifiuta le richieste provenienti da altri siti, e le impostazioni dell'IA si possono modificare solo dal computer su cui gira l'app.

## Configurazione

Copia `.env.example` in `.env` nella cartella del progetto e modificalo; ogni impostazione vi è spiegata, in arabo e in inglese. Il file viene letto all'avvio, quindi riavvia Tarjuman dopo una modifica. Una variabile impostata nell'ambiente reale ha la precedenza sul file.

| Variabile d'ambiente | Predefinito | Significato |
|---|---|---|
| `TARJUMAN_HOME` | cartella del progetto | Dove viene tenuta `data/` |
| `TARJUMAN_PORT` | `4318` | Prima porta da provare (se è occupata passa alla successiva; l'estensione si adegua) |
| `TARJUMAN_HOST` | `0.0.0.0` | Usa `127.0.0.1` per non esporre l'app sulla tua rete Wi-Fi |
| `TARJUMAN_WHISPER_MODEL` | `base` | `small` o `medium` per una trascrizione più accurata (più lenta) |
| `TARJUMAN_VOICE_CACHE_GB` | `2` | Limite di spazio per le voci di doppiaggio salvate; si eliminano prima quelle usate meno di recente |
| `TARJUMAN_MAX_UPLOAD_GB` | `8` | Dimensione massima del video che puoi caricare |
| `TARJUMAN_PAIR_MINUTES` | `15` | Per quanto tempo resta valido un codice di abbinamento del telefono (il QR); `0` = finché non ne crei uno nuovo |
| `TARJUMAN_FETCH_PRIVATE` | disattivato | Imposta `1` per consentire il download da indirizzi interni alla tua rete |
| `TARJUMAN_HEAVY_JOBS` | `2` | Quante attività pesanti (Whisper, doppiaggio, impressione dei sottotitoli) girano insieme; usa `1` su un computer con poca memoria |
| `TARJUMAN_MAX_QUEUE` | `20` | Numero massimo di attività che possono attendere il proprio turno |
| `TARJUMAN_FORCE_ASR` | disattivato | Imposta `1` per trascrivere sempre con Whisper, ignorando i sottotitoli di YouTube |
| `ANTHROPIC_API_KEY` | – | Usata per Claude quando nelle impostazioni non è salvata alcuna chiave |

## Struttura del progetto

```
backend/     Python package `tarjuman` (FastAPI): captions, translation, voices, dubbing, AI, jobs
frontend/    Vue 3 + Vite + TypeScript web app
extension/   Chrome / Edge extension (Manifest V3, Vue + Vite) and its store kit
shared/      the live dub engine used by both the web app and the extension
assets/      brand (icon source and renders)
docs/        plan, specification, implementation notes, translated READMEs, screenshots
```

## Sviluppo

```sh
# backend tests (offline)
cd backend && ../.venv/bin/python -m pytest      # Windows: ..\.venv\Scripts\python

# dub engine tests
npm test

# web app with hot reload (proxies the API to 127.0.0.1:4318)
npm --prefix frontend run dev

# extension: build, test, package a store zip
npm --prefix extension run build && npm --prefix extension test && npm --prefix extension run package
```

Leggi [docs/specs.md](../specs.md) prima di modificare una route dell'API: sia l'app web sia l'estensione ne dipendono.

### Creare il programma di installazione per Windows

```powershell
powershell -ExecutionPolicy Bypass -File installer\build.ps1   # build\windows\app: Python, packages, web app, extension
iscc /DAppVersion=3.0.0 installer\tarjuman.iss                # build\windows\Tarjuman-Setup-3.0.0.exe (Inno Setup 6)
```

Il workflow *Windows installer* fa lo stesso su GitHub: avvialo dalla scheda Actions, oppure invia un tag come `v3.0.0` per allegare il programma di installazione a una release. Prima di compilare, avvia l'app inclusa nel pacchetto e verifica che risponda.
