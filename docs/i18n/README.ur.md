## یہ کیا کرتا ہے

YouTube کا لنک پیسٹ کریں، اپنے کمپیوٹر سے ویڈیو اپ لوڈ کریں، یا تقریباً کسی بھی سائٹ کا لنک دیں۔

- **ہم وقت سب ٹائٹلز۔** عربی سب ٹائٹلز ویڈیو پر سطر بہ سطر نظر آتے ہیں، اور چاہیں تو نیچے اصل زبان بھی۔ خودکار کیپشنز کو ترجمے سے پہلے مکمل جملوں میں جوڑ دیا جاتا ہے۔ اور اگر ان میں سرے سے کوئی رموزِ اوقاف نہ ہوں تو YouTube کی ہر لفظ کی ٹائمنگ کی مدد سے انہیں وہیں سے توڑا جاتا ہے جہاں بولنے والا واقعی رکتا ہے۔
- **انسان جیسی آواز والی لائیو ڈبنگ۔** ایک نیورل عربی آواز ہر جملہ بولنے والے کے ساتھ ساتھ ادا کرتی ہے، مصری، سعودی، اماراتی، شامی، اردنی، لبنانی، مراکشی یا عراقی عربی میں۔ کوئی جملہ نہ کٹتا ہے نہ چھوٹتا ہے۔ تیز بولنے والے کے ساتھ آواز کو دوڑانے کے بجائے ویڈیو تھوڑی دھیمی ہو جاتی ہے تاکہ آواز ساتھ آ ملے؛ اور اگر آپ خود ویڈیو دھیمی کریں تو وہ اضافی وقت آواز کو مل جاتا ہے۔ جو الفاظ لکھنے میں ایک جیسے مگر پڑھنے میں مختلف ہوں، وہ جملے کے مطلب کے مطابق پڑھے جاتے ہیں (الجُمَل یعنی "جملے"، نہ کہ الجَمَل یعنی "اونٹ")، اور اس کا فیصلہ انگریزی اصل سے ہوتا ہے۔
- **ڈب شدہ MP4۔** ویڈیو کو عربی وائس اوور کے ساتھ ایکسپورٹ کریں۔ یہ موسیقی اور ایفیکٹس برقرار رکھتے ہوئے اصل بولنے والے کی آواز ہٹا سکتا ہے، ہر بولنے والے کو موزوں مردانہ یا زنانہ آواز دے سکتا ہے، اور سب ٹائٹلز شامل یا ویڈیو میں ثبت کر سکتا ہے۔
- **کیپشنز نہیں؟ کوئی مسئلہ نہیں۔** Whisper آپ کے کمپیوٹر پر آڈیو کو تحریر میں بدلتا ہے، پھر اس تحریر کا ترجمہ ہوتا ہے۔
- **سب ٹائٹل فائلیں۔** SRT، VTT یا سادہ متن ڈاؤن لوڈ کریں، عربی میں یا دو لسانی، یا شیئر کرنے کے لیے تیار سب ٹائٹل والی MP4۔
- **پوری پلے لسٹس۔** پلے لسٹ یا چینل کا لنک دیں تاکہ اس کی ہر ویڈیو کے لیے سب ٹائٹلز، سب ٹائٹل والی ویڈیوز یا ڈب شدہ ویڈیوز بن جائیں۔
- **ویڈیو سے پوچھیں** (اختیاری AI)۔ خلاصہ، اہم نکات، کلک کیے جا سکنے والے ابواب، اور ایسے جوابات حاصل کریں جو آپ کو اس لمحے پر لے جائیں جہاں ویڈیو آپ کے سوال پر بات کرتی ہے۔ Claude یا کسی بھی OpenAI سے مطابقت رکھنے والے فراہم کنندہ (Gemini، Groq، OpenRouter، Ollama) کے ساتھ کام کرتا ہے۔
- **انگریزی سیکھیں۔** کسی بھی لفظ پر ٹیپ کر کے اس کا مطلب دیکھیں، اسے اس کے جملے سمیت محفوظ کریں، بعد میں دہرائیں، اور Anki میں ایکسپورٹ کریں۔ آپ کوئی جملہ دہرا بھی سکتے ہیں، ہر سطر کے بعد روک سکتے ہیں، یا خود کو آزمانے کے لیے سب ٹائٹلز دھندلا سکتے ہیں۔
- **براؤزر ایکسٹینشن۔** یہی سب ٹائٹلز اور ڈبنگ براہ راست YouTube پر، ان سائٹس پر جن کے پلیئر میں کیپشنز ہوں (Coursera، Udemy وغیرہ)، فلموں اور اینیمے کی ان سائٹس پر جو اپنا پلیئر کسی دوسری سائٹ سے ایمبیڈ کرتی ہیں، یا ٹیب کی آڈیو سن کر کسی بھی دوسری سائٹ پر استعمال کریں۔
- **اپنے فون پر۔** اسی Wi-Fi سے جڑے کسی بھی فون سے ایپ کھولیں۔

دوسری زبانیں بھی چلتی ہیں: فرانسیسی، ہسپانوی، جرمن، ترکی اور انگریزی ہدف زبانوں کے طور پر شامل ہیں۔

## فوری آغاز

### Windows انسٹالر

[Releases](https://github.com/MohamedElnagar94/tarjuman/releases) صفحے سے `Tarjuman-Setup-<version>.exe` ڈاؤن لوڈ کر کے چلائیں۔ اس کے ساتھ اپنا Python، تمام پیکجز، ویب ایپ اور براؤزر ایکسٹینشن آتے ہیں، اس لیے آپ کو نہ Python درکار ہے نہ Node.js۔ یہ ایک بار ایڈمنسٹریٹر کے اختیارات مانگتا ہے، Program Files میں انسٹال ہوتا ہے، اور فائر وال کو نہیں چھیڑتا۔ اس کے بعد ترجمان کسی بھی ڈیسک ٹاپ ایپ کی طرح اپنی الگ ونڈو میں کھلتا ہے، نہ کنسول ونڈو ہوتی ہے نہ براؤزر ٹیب؛ ونڈو بند کرنے سے یہ رک جاتا ہے۔ (یہ ونڈو ایپ موڈ میں Microsoft Edge ہے، جو ہر Windows 10 اور 11 میں موجود ہے؛ کچھ اضافی انسٹال نہیں ہوتا۔)

- اگر Setup فوراً "unable to create the directory ...\Temp\is-*.tmp, access is denied" کے ساتھ رک جائے تو انسٹالر فائل ایسے فولڈر میں پڑی ہے جس پر کم انٹیگریٹی کا نشان لگا ہے (کچھ سینڈ باکسنگ ٹولز اپنے ورکنگ فولڈرز پر یہی نشان لگاتے ہیں؛ تب `icacls <file>` میں `Low Mandatory Level` نظر آتا ہے)۔ Windows ایسی فائل کو کم اختیارات کے ساتھ چلاتا ہے۔ اسے کسی دوسرے فولڈر، مثلاً Downloads، میں کاپی کریں اور وہ کاپی چلائیں۔
- انسٹالر پر ابھی کوڈ سائننگ نہیں ہوئی، اس لیے Windows SmartScreen "نامعلوم پبلشر" کہہ سکتا ہے: *More info → Run anyway* منتخب کریں۔
- پہلی بار شروع ہونے پر آف لائن عربی آواز (تقریباً 60 MB) پس منظر میں ڈاؤن لوڈ ہوتی ہے۔ Whisper ماڈل اس وقت خود ڈاؤن لوڈ ہو جاتا ہے جب پہلی بار کسی ویڈیو کو اس کی ضرورت پڑے۔
- آپ کی ویڈیوز، سب ٹائٹلز، سیٹنگز اور `.env` پروگرام سے الگ `%LOCALAPPDATA%\Tarjuman` میں رکھے جاتے ہیں۔ اپ ڈیٹ انہیں برقرار رکھتی ہے؛ اَن انسٹال کرتے وقت پوچھا جاتا ہے کہ انہیں حذف کرنا ہے یا نہیں۔
- Start مینو میں ایکسٹینشن فولڈر کا شارٹ کٹ موجود ہے، تاکہ `chrome://extensions` میں *ان پیکڈ لوڈ کریں* کے ساتھ استعمال ہو سکے۔

کچھ کام نہیں کر رہا؟ [مسائل کا حل](../troubleshooting.md) دیکھیں۔ ہر ورژن میں کیا بدلا، یہ [تبدیلیوں کی فہرست](../../CHANGELOG.md) میں درج ہے۔

### سورس کوڈ سے

آپ کو **Python 3.11+** اور **Node.js 20+** درکار ہیں۔

**Windows:** `start.cmd` پر ڈبل کلک کریں۔ اگر Windows پوچھے کہ نامعلوم پبلشر کا اسکرپٹ چلانا ہے یا نہیں، تو ایک بار `powershell -ExecutionPolicy Bypass -File scripts/create-shortcut.ps1` سے ڈیسک ٹاپ شارٹ کٹ بنا لیں اور ترجمان اسی سے شروع کریں؛ یہ وہی اسکرپٹ Windows کے اپنے `cmd.exe` کے ذریعے چلاتا ہے، اس لیے یہ سوال سامنے نہیں آتا۔

**macOS / Linux:**

```sh
./start.sh
```

Debian، Ubuntu اور Kali پر اگر `python3-venv` موجود نہ ہو تو پہلے اسے انسٹال کریں (`sudo apt install python3-venv`)۔

پہلی بار چلانے پر سب کچھ انسٹال ہو جاتا ہے: Python پیکجز، آف لائن عربی آواز، اور ویب ایپ کا بلڈ۔ پھر ایپ `http://127.0.0.1:4318` پر کھل جاتی ہے۔ اگلی بار یہ چند سیکنڈ میں شروع ہو جاتی ہے۔ فون سے استعمال کرنے کے لیے وہ پتہ کھولیں جو یہ آپ کے Wi-Fi کے لیے دکھاتی ہے۔ Windows پر اگر فون اس تک نہ پہنچ پائے تو ایک بار بطور ایڈمنسٹریٹر `scripts/allow-phone.ps1` چلائیں: یہ آپ کے گھر کے Wi-Fi کو Private قرار دیتا ہے اور ترجمان کے پورٹس صرف Private نیٹ ورکس پر کھولتا ہے۔

### کمانڈز

| کمانڈ | کیا کرتی ہے |
|---|---|
| `python -m tarjuman` | ایپ شروع کرتی ہے (`--port`، صرف اسی کمپیوٹر کے لیے `--host 127.0.0.1`، `--no-open`) |
| `python -m tarjuman app` | ایپ کو براؤزر ٹیب کے بجائے اس کی اپنی ونڈو میں شروع کرتی ہے (ایپ موڈ میں Edge یا Chrome)؛ ونڈو بند کرنے سے ایپ رک جاتی ہے |
| `python -m tarjuman subs <link>` | سب ٹائٹل فائلیں `data/output` میں لکھتی ہے (`--lang`، `--format srt,vtt,txt`) |
| `python -m tarjuman setup` | سب کچھ انسٹال یا ٹھیک کرتی ہے |
| `python -m tarjuman update` | اگر ڈاؤن لوڈ یا آوازیں کام کرنا بند کر دیں تو yt-dlp اور وائس کلائنٹ کو اپ ڈیٹ کرتی ہے |
| `python -m tarjuman doctor` | ہر جزو کی جانچ کرتی ہے |

## براؤزر ایکسٹینشن

<p align="center">
  <img src="../screenshots/extension-popup.png" alt="ترجمان ایکسٹینشن کا پاپ اپ" width="320">
</p>

1. اسے ایک بار بلڈ کریں: `npm --prefix extension install && npm --prefix extension run build`۔
2. `chrome://extensions` (یا `edge://extensions`) کھولیں، **ڈویلپر موڈ** آن کریں، **ان پیکڈ لوڈ کریں** پر کلک کریں، اور `extension/dist` منتخب کریں۔
3. ایپ چلتی رہنے دیں، کوئی ویڈیو کھولیں، اور ترجمان کے آئیکن پر کلک کریں، یا <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> دبائیں۔

ایکسٹینشن صرف آپ کے کمپیوٹر پر موجود ایپ سے بات کرتی ہے۔ اس کی Chrome Web Store کٹ (لسٹنگ کا متن، اجازتوں کا جواز، رازداری کی پالیسی، تشہیری تصاویر) [`extension/store`](../../extension/store) میں ہے۔

## ڈبنگ ہم وقت کیسے رہتی ہے

کیپشن کی سطروں کو مکمل جملوں میں جوڑا جاتا ہے اور بھرتی کے الفاظ ہٹا دیے جاتے ہیں۔ پھر ہر جملے کی رفتار تقریباً 12 سیکنڈ کی آگے دیکھنے والی ونڈو کی بنیاد پر طے ہوتی ہے، تاکہ کشادہ جملہ تنگ جملے کو وقت ادھار دے اور رفتار اچانک بدلنے کے بجائے بتدریج بدلے۔ براؤزر کے ہر حصے کے پہلے جملے چلانے سے پہلے سرور انہیں آواز میں ڈھال کر ان کا دورانیہ ناپتا ہے، اس لیے منصوبہ اندازوں کے بجائے حقیقی دورانیوں پر مبنی ہوتا ہے، اور اگلا حصہ وہ پس منظر میں تیار کرتا ہے۔ اگر پھر بھی ڈبنگ پیچھے رہ جائے تو ویڈیو آپ کی رفتار کے 85% تک دھیمی ہو جاتی ہے جب تک آواز ساتھ نہ آ ملے، اور صرف تب رکتی ہے جب فرق تقریباً دو سیکنڈ سے بڑھ جائے۔ رفتار آپ کی پلے بیک اسپیڈ کے مطابق چلتی ہے۔ کہیں بھی آگے پیچھے جائیں، ڈبنگ ٹھیک اسی جگہ سے دوبارہ شروع ہوتی ہے۔ جب مفت ترجمہ سروسز درخواستوں کی حد لگا دیں تو Google کا ایک دوسرا اینڈ پوائنٹ اور پھر YouTube کا اپنا ترجمہ ڈبنگ کو جاری رکھتے ہیں۔

## رازداری

ترجمان بنیادی طور پر مقامی طور پر کام کرتا ہے۔ آپ کی ویڈیوز، سب ٹائٹلز، محفوظ کیے گئے الفاظ، سیٹنگز اور API کلید آپ کے کمپیوٹر پر `data/` فولڈر میں رہتی ہیں۔ ایپ YouTube (کیپشنز اور ڈاؤن لوڈز)، Google Translate اور MyMemory (ترجمہ)، Microsoft کی Edge وائس سروس (آواز) اور، صرف اگر آپ اسے آن کریں، آپ کے منتخب کردہ AI فراہم کنندہ سے رابطہ کرتی ہے۔ نہ اکاؤنٹس ہیں، نہ اینالیٹکس، نہ ٹریکنگ۔ ویڈیو اور آڈیو کبھی کہیں اپ لوڈ نہیں ہوتیں۔

| فیچر | آپ کے کمپیوٹر سے کیا باہر جاتا ہے | کسے بھیجا جاتا ہے | کچھ بھیجے بغیر |
|---|---|---|---|
| YouTube کیپشنز | ویڈیو کا لنک | YouTube | فائل اپ لوڈ کریں؛ اسے مقامی طور پر تحریر میں بدلا جاتا ہے |
| ترجمہ | ویڈیو کے جملے، متن کی صورت میں | Google Translate، پھر MyMemory | ابھی کوئی طریقہ نہیں؛ محفوظ شدہ جملے آف لائن بھی کام کرتے ہیں |
| ڈبنگ کی آواز | ہر ترجمہ شدہ جملہ اور آواز کا نام | Microsoft Edge کی آوازیں، پھر Google | Piper، مقامی عربی آواز |
| ویڈیو ڈاؤن لوڈ | ویڈیو کی درخواست | وہ سائٹ جس پر ویڈیو موجود ہے | ایسی فائل جو پہلے سے آپ کے کمپیوٹر پر ہو |
| AI (اختیاری، ڈیفالٹ طور پر بند) | ویڈیو کا متن اور آپ کا سوال | آپ کا منتخب کردہ فراہم کنندہ | اسے بند رہنے دیں، یا Ollama جیسا مقامی سرور استعمال کریں |
| ماڈلز کے ڈاؤن لوڈ | ڈاؤن لوڈ کی درخواست، صرف ایک بار | Hugging Face، GitHub | پہلے ڈاؤن لوڈ کے بعد کچھ نہیں |
| آواز کی شناخت، موسیقی کی علیحدگی، آپ کی فائلیں | کچھ نہیں | – | ہمیشہ مقامی |

یہی جدول ایپ میں بھی سیٹنگز → رازداری کے تحت موجود ہے۔ API دوسری ویب سائٹس کی درخواستیں مسترد کر دیتی ہے، اور AI سیٹنگز صرف اسی کمپیوٹر سے بدلی جا سکتی ہیں جس پر ایپ چل رہی ہو۔

## کنفیگریشن

پروجیکٹ فولڈر میں `.env.example` کو `.env` کے نام سے کاپی کریں اور اس میں ترمیم کریں؛ ہر سیٹنگ کی وضاحت وہیں عربی اور انگریزی میں موجود ہے۔ یہ فائل شروع ہوتے وقت پڑھی جاتی ہے، اس لیے تبدیلی کے بعد ترجمان کو دوبارہ شروع کریں۔ اصل انوائرنمنٹ میں سیٹ کیا گیا ویری ایبل فائل پر فوقیت رکھتا ہے۔

| انوائرنمنٹ ویری ایبل | ڈیفالٹ | مطلب |
|---|---|---|
| `TARJUMAN_HOME` | پروجیکٹ فولڈر | جہاں `data/` رکھا جاتا ہے |
| `TARJUMAN_PORT` | `4318` | آزمایا جانے والا پہلا پورٹ (مصروف ہو تو اگلا لیتا ہے؛ ایکسٹینشن بھی ساتھ چلتی ہے) |
| `TARJUMAN_HOST` | `0.0.0.0` | ایپ کو اپنے Wi-Fi سے دور رکھنے کے لیے `127.0.0.1` استعمال کریں |
| `TARJUMAN_WHISPER_MODEL` | `base` | زیادہ درست (مگر سست) ٹرانسکرپشن کے لیے `small` یا `medium` |
| `TARJUMAN_VOICE_CACHE_GB` | `2` | محفوظ ڈبنگ آوازوں کی حدِ حجم؛ سب سے کم حال میں استعمال ہونے والی پہلے حذف ہوتی ہیں |
| `TARJUMAN_MAX_UPLOAD_GB` | `8` | سب سے بڑی ویڈیو جو آپ اپ لوڈ کر سکتے ہیں |
| `TARJUMAN_PAIR_MINUTES` | `15` | فون جوڑنے کا کوڈ (QR) کتنے منٹ کارآمد رہتا ہے؛ `0` = جب تک آپ نیا نہ بنائیں |
| `TARJUMAN_FETCH_PRIVATE` | بند | اپنے ہی نیٹ ورک کے اندر کے پتوں سے ڈاؤن لوڈ کی اجازت دینے کے لیے `1` سیٹ کریں |
| `TARJUMAN_HEAVY_JOBS` | `2` | کتنے بھاری کام (Whisper، ڈبنگ، سب ٹائٹلز ویڈیو میں ثبت کرنا) ایک ساتھ چلتے ہیں؛ کم میموری والے کمپیوٹر پر `1` استعمال کریں |
| `TARJUMAN_MAX_QUEUE` | `20` | زیادہ سے زیادہ کتنے کام اپنی باری کا انتظار کر سکتے ہیں |
| `TARJUMAN_FORCE_ASR` | بند | YouTube کے کیپشنز کو نظر انداز کر کے ہمیشہ Whisper سے ٹرانسکرپشن کرنے کے لیے `1` سیٹ کریں |
| `ANTHROPIC_API_KEY` | – | جب سیٹنگز میں کوئی کلید محفوظ نہ ہو تو Claude کے لیے استعمال ہوتی ہے |

## پروجیکٹ کی ساخت

```
backend/     Python package `tarjuman` (FastAPI): captions, translation, voices, dubbing, AI, jobs
frontend/    Vue 3 + Vite + TypeScript web app
extension/   Chrome / Edge extension (Manifest V3, Vue + Vite) and its store kit
shared/      the live dub engine used by both the web app and the extension
assets/      brand (icon source and renders)
docs/        plan, specification, implementation notes, translated READMEs, screenshots
```

## ڈویلپمنٹ

```sh
# backend tests (offline)
cd backend && ../.venv/bin/python -m pytest      # Windows: ..\.venv\Scripts\python

# dub engine tests
npm test

# web app with hot reload (proxies the API to 127.0.0.1:4318)
npm --prefix frontend run dev

# extension: build, test, package a store zip
npm --prefix extension run build && npm --prefix extension test && npm --prefix extension run package
```

کسی API روٹ کو بدلنے سے پہلے [docs/specs.md](../specs.md) پڑھیں: ویب ایپ اور ایکسٹینشن دونوں اسی پر انحصار کرتے ہیں۔

### Windows انسٹالر بنانا

```powershell
powershell -ExecutionPolicy Bypass -File installer\build.ps1   # build\windows\app: Python, packages, web app, extension
iscc /DAppVersion=3.0.0 installer\tarjuman.iss                # build\windows\Tarjuman-Setup-3.0.0.exe (Inno Setup 6)
```

*Windows installer* ورک فلو یہی کام GitHub پر کرتا ہے: اسے Actions ٹیب سے چلائیں، یا انسٹالر کو کسی ریلیز کے ساتھ منسلک کرنے کے لیے `v3.0.0` جیسا ٹیگ پُش کریں۔ کمپائل کرنے سے پہلے یہ بنڈل شدہ ایپ کو شروع کر کے جانچتا ہے کہ وہ جواب دے رہی ہے۔
