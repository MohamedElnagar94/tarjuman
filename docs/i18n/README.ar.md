## ماذا يفعل

الصق رابطًا من YouTube، أو ارفع فيديو من جهازك، أو أعطه رابطًا من أي موقع تقريبًا.

- **ترجمة متزامنة.** تظهر الترجمة العربية على الفيديو سطرًا بسطر، ومعها النص الأصلي أسفلها إن أردت. وتُجمع النصوص المولَّدة تلقائيًا في جمل كاملة قبل ترجمتها. وإذا خلت من علامات الترقيم تمامًا، قُسِّمت عند المواضع التي يتوقف فيها المتحدث فعلًا، اعتمادًا على توقيت كل كلمة في YouTube.
- **دبلجة حية تبدو كصوت إنسان.** صوت عربي مولَّد بالشبكات العصبية ينطق كل جملة في توقيتها مع المتحدث، باللهجة المصرية أو السعودية أو الإماراتية أو السورية أو الأردنية أو اللبنانية أو المغربية أو العراقية. لا تُقطع جملة ولا تُتخطّى. ومع المتحدث السريع يتباطأ الفيديو قليلًا ريثما يلحق به الصوت، بدلًا من أن يتسارع الصوت؛ وإذا أبطأت الفيديو بنفسك نال الصوت ذلك الوقت الإضافي. والكلمات المتماثلة في الكتابة المختلفة في النطق تُقرأ وفق معنى الجملة (الجُمَل جمعُ جملة، لا الجَمَل الحيوان)، ويُحسم ذلك بالرجوع إلى الأصل الإنجليزي.
- **MP4 مدبلج.** صدّر الفيديو بالتعليق الصوتي العربي. يمكنه حذف صوت المتحدث الأصلي مع الإبقاء على الموسيقى والمؤثرات، وإعطاء كل متحدث صوتًا مناسبًا ذكوريًا أو أنثويًا، وتضمين الترجمة أو دمجها في الصورة.
- **لا يوجد نص للفيديو؟ لا مشكلة.** يحوّل Whisper الصوت إلى نص على جهازك، ثم يُترجم النص.
- **ملفات الترجمة.** نزّل SRT أو VTT أو نصًا عاديًا، بالعربية أو بلغتين، أو ملف MP4 مترجمًا جاهزًا للمشاركة.
- **قوائم تشغيل كاملة.** أعطه رابط قائمة تشغيل أو قناة ليصنع الترجمات أو مقاطع الفيديو المترجمة أو المدبلجة لكل فيديو فيها.
- **اسأل الفيديو** (ذكاء اصطناعي اختياري). احصل على ملخص، وأهم النقاط، وفصول قابلة للنقر، وإجابات تنقلك إلى اللحظة التي يتناول فيها الفيديو سؤالك. يعمل مع Claude أو أي مزوّد متوافق مع OpenAI (Gemini وGroq وOpenRouter وOllama).
- **تعلّم الإنجليزية.** انقر أي كلمة لترى معناها، واحفظها مع جملتها، وراجعها لاحقًا، وصدّرها إلى Anki. ويمكنك أيضًا تكرار جملة، أو الإيقاف بعد كل سطر، أو تمويه الترجمة لتختبر نفسك.
- **إضافة المتصفح.** استخدم الترجمة والدبلجة نفسيهما على YouTube مباشرة، وعلى المواقع التي يوفّر مشغّلها ترجمات (Coursera وUdemy وغيرهما)، وعلى مواقع الأفلام والأنمي التي تضمّن مشغّلها من موقع آخر، أو على أي موقع آخر عبر الاستماع إلى صوت التبويب.
- **على هاتفك.** افتح التطبيق من أي هاتف متصل بشبكة Wi-Fi نفسها.

ولغات أخرى تعمل أيضًا: الفرنسية والإسبانية والألمانية والتركية والإنجليزية مدمجة كلغات هدف.

## البدء السريع

### مثبّت Windows

نزّل `Tarjuman-Setup-<version>.exe` من صفحة [الإصدارات](https://github.com/MohamedElnagar94/tarjuman/releases) وشغّله. يأتي المثبّت ومعه Python الخاص به، وكل الحزم، وتطبيق الويب، وإضافة المتصفح، فلا تحتاج إلى Python ولا إلى Node.js. يطلب صلاحيات المسؤول مرة واحدة، ويثبّت البرنامج في Program Files، ولا يمسّ جدار الحماية. ثم يُفتح ترجمان في نافذة خاصة به، مثل أي تطبيق لسطح المكتب، بلا نافذة أوامر ولا تبويب في المتصفح؛ وإغلاق النافذة يوقفه. (النافذة هي Microsoft Edge في وضع التطبيق، وهو موجود في كل نسخة من Windows 10 و11؛ فلا يُثبَّت شيء إضافي.)

- إذا توقف برنامج التثبيت فورًا برسالة "unable to create the directory ...\Temp\is-*.tmp, access is denied"، فملف المثبّت موجود في مجلد موسوم بمستوى سلامة منخفض (بعض أدوات العزل تَسِم مجلدات عملها بهذه الطريقة؛ وعندئذ يُظهر الأمر `icacls <file>` العبارة `Low Mandatory Level`). ويشغّل Windows ملفًا كهذا بصلاحيات أقل. انسخه إلى مجلد آخر، مثل مجلد التنزيلات، وشغّل النسخة.
- المثبّت غير موقَّع رقميًا بعد، فقد يعرض Windows SmartScreen عبارة «ناشر غير معروف»: اختر *مزيد من المعلومات ← التشغيل على أي حال*.
- يُنزَّل الصوت العربي الذي يعمل دون اتصال (نحو 60 ميغابايت) في الخلفية عند التشغيل الأول. أما نموذج Whisper فيُنزَّل تلقائيًا أول مرة يحتاج إليه فيديو.
- تُحفظ مقاطعك وترجماتك وإعداداتك وملف `.env` في `%LOCALAPPDATA%\Tarjuman`، بمعزل عن البرنامج. التحديث يبقيها، وإلغاء التثبيت يسألك هل تريد حذفها.
- في قائمة «ابدأ» اختصار إلى مجلد الإضافة، لاستخدامه مع *تحميل إضافة غير مضغوطة* في `chrome://extensions`.

هل هناك ما لا يعمل؟ راجع [حل المشكلات](../troubleshooting.md). وما تغيّر في كل إصدار مدوَّن في [سجل التغييرات](../../CHANGELOG.md).

### من المصدر

تحتاج إلى **Python 3.11+** و**Node.js 20+**.

**Windows:** انقر نقرًا مزدوجًا على `start.cmd`. وإذا سألك Windows عن تشغيل برنامج نصي من ناشر غير معروف، فأنشئ اختصارًا على سطح المكتب مرة واحدة بالأمر `powershell -ExecutionPolicy Bypass -File scripts/create-shortcut.ps1` وشغّل ترجمان منه؛ فهو يشغّل البرنامج النصي نفسه عبر `cmd.exe` الخاص بـ Windows، فلا تظهر تلك الرسالة.

**macOS / Linux:**

```sh
./start.sh
```

على Debian وUbuntu وKali، ثبّت `python3-venv` أولًا إن لم يكن موجودًا (`sudo apt install python3-venv`).

يثبّت التشغيل الأول كل شيء: حزم Python، والصوت العربي الذي يعمل دون اتصال، ونسخة مبنية من تطبيق الويب. ثم يُفتح التطبيق على `http://127.0.0.1:4318`. وفي المرات التالية يبدأ خلال ثانيتين تقريبًا. ولاستخدامه من هاتفك، افتح العنوان الذي يطبعه لشبكة Wi-Fi. وعلى Windows، إذا تعذّر على الهاتف الوصول إليه، فشغّل `scripts/allow-phone.ps1` مرة واحدة بصلاحيات المسؤول: فهو يجعل شبكة Wi-Fi المنزلية شبكة خاصة (Private)، ويفتح منافذ ترجمان على الشبكات الخاصة فقط.

<details>
<summary>الإعداد اليدوي</summary>

```sh
python -m venv .venv
.venv/bin/pip install -r backend/requirements.txt        # Windows: .venv\Scripts\pip
npm --prefix frontend install && npm --prefix frontend run build
PYTHONPATH=backend .venv/bin/python -m tarjuman           # Windows: set PYTHONPATH=backend
```

</details>

### الأوامر

| الأمر | وظيفته |
|---|---|
| `python -m tarjuman` | تشغيل التطبيق (`--port`، و`--host 127.0.0.1` لهذا الجهاز فقط، و`--no-open`) |
| `python -m tarjuman app` | تشغيل التطبيق في نافذة خاصة به (Edge أو Chrome في وضع التطبيق) بدلًا من تبويب في المتصفح؛ وإغلاق النافذة يوقفه |
| `python -m tarjuman subs <link>` | كتابة ملفات الترجمة في `data/output` (`--lang`، `--format srt,vtt,txt`) |
| `python -m tarjuman setup` | تثبيت كل شيء أو إصلاحه |
| `python -m tarjuman update` | تحديث yt-dlp وعميل الأصوات، إذا توقف التنزيل أو الأصوات عن العمل |
| `python -m tarjuman doctor` | فحص كل المكونات |

## إضافة المتصفح

<p align="center">
  <img src="../screenshots/extension-popup.png" alt="النافذة المنبثقة لإضافة ترجمان" width="320">
</p>

ثبّتها مباشرة من [سوق Chrome الإلكتروني](https://chromewebstore.google.com/detail/gcfnomfbpenbhdebopmpdfamlaiodflp)، أو ابنِها من المصدر بالخطوات التالية:

1. ابنِها مرة واحدة: `npm --prefix extension install && npm --prefix extension run build`.
2. افتح `chrome://extensions` (أو `edge://extensions`)، وفعّل **وضع مطوّر البرامج**، وانقر **تحميل إضافة غير مضغوطة**، واختر `extension/dist`.
3. أبقِ التطبيق يعمل، وافتح فيديو، وانقر أيقونة ترجمان، أو اضغط <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd>.

إن عرض Chrome تحذير *Proceed with caution: this extension is not trusted by Enhanced Safe Browsing*، فسببه أن الناشر جديد على سوق Chrome الإلكتروني: يعرضه Chrome لكل ناشر جديد حتى يلتزم بسياسات المتجر بضعة أشهر، ولا يراه إلا من فعّل الحماية المحسّنة. اجتازت الإضافة مراجعة المتجر، و[كودها](https://github.com/MohamedElnagar94/tarjuman/tree/main/extension) مفتوح المصدر. اختر *Continue to install*.

لا تتواصل الإضافة إلا مع التطبيق الموجود على جهازك. وحزمة متجر Chrome Web Store الخاصة بها (نص الصفحة، ومبررات الأذونات، وسياسة الخصوصية، والصور الترويجية) موجودة في [`extension/store`](../../extension/store).

## كيف تبقى الدبلجة متزامنة

تُدمج أسطر الترجمة في جمل كاملة، وتُحذف حشوات الكلام. ثم تُحدَّد سرعة كل جملة بناءً على نافذة استباقية مدتها نحو 12 ثانية، فتُعير الجملة التي لديها متّسع من الوقت جزءًا منه لجملة مزدحمة، وتتغير السرعة تدريجيًا بدل أن تقفز. وقبل أن يشغّل المتصفح الجمل الأولى من كل مقطع، يولّدها الخادم صوتيًا ويقيس مدتها، فتقوم الخطة على مُدد حقيقية لا على تخمين، ويجهّز الخادم المقطع التالي في الخلفية. وإذا تأخرت الدبلجة رغم ذلك، يتباطأ الفيديو إلى 85% من سرعتك حتى يلحق به الصوت، ولا يتوقف إلا إذا تجاوز الفارق ثانيتين تقريبًا. ويتبع الإيقاع سرعة التشغيل التي تختارها. والانتقال إلى أي موضع يستأنف الدبلجة من النقطة نفسها بالضبط. وحين تقيّد خدمات الترجمة المجانية عدد الطلبات، تُبقي نقطةُ وصول ثانية من Google، ثم ترجمةُ YouTube نفسها، الدبلجةَ مستمرة.

التصميم الكامل في [docs/implementation.md](../implementation.md).

## الخصوصية

ترجمان يعمل محليًا أولًا. تبقى مقاطعك وترجماتك وكلماتك المحفوظة وإعداداتك ومفتاح API في مجلد `data/` على جهازك. يتصل التطبيق بـ YouTube (الترجمات والتنزيلات)، وGoogle Translate وMyMemory (الترجمة)، وخدمة أصوات Edge من Microsoft (النطق)، وبمزوّد الذكاء الاصطناعي الذي تختاره فقط إذا فعّلته. لا حسابات ولا إحصاءات ولا تتبّع. ولا يُرفع الفيديو ولا الصوت إلى أي مكان أبدًا.

| الميزة | ما يغادر جهازك | يُرسَل إلى | دون إرسال أي شيء |
|---|---|---|---|
| ترجمات YouTube | رابط الفيديو | YouTube | ارفع ملفًا؛ فيُفرَّغ صوته محليًا |
| الترجمة | جمل الفيديو، نصًّا | Google Translate، ثم MyMemory | لا يوجد بعد؛ والجمل المحفوظة تبقى تعمل دون اتصال |
| صوت الدبلجة | كل جملة مترجمة واسم الصوت | أصوات Microsoft Edge، ثم Google | Piper، الصوت العربي المحلي |
| تنزيل الفيديو | طلب للفيديو | الموقع الذي يستضيفه | ملف موجود على جهازك |
| الذكاء الاصطناعي (اختياري، ومعطّل افتراضيًا) | نص الفيديو وسؤالك | المزوّد الذي اخترته | أبقِه معطّلًا، أو استخدم خادمًا محليًا مثل Ollama |
| تنزيل النماذج | طلب تنزيل، مرة واحدة | Hugging Face وGitHub | لا شيء بعد التنزيل الأول |
| التعرّف على الكلام، وفصل الموسيقى، وملفاتك | لا شيء | – | محلي دائمًا |

الجدول نفسه موجود في التطبيق، ضمن الإعدادات ← الخصوصية. ويرفض الـ API الطلبات الواردة من مواقع أخرى، ولا يمكن تغيير إعدادات الذكاء الاصطناعي إلا من الجهاز الذي يعمل عليه التطبيق.

## الإعدادات

انسخ `.env.example` إلى `.env` في مجلد المشروع وعدّله؛ فكل إعداد مشروح فيه بالعربية والإنجليزية. يُقرأ الملف عند بدء التشغيل، فأعد تشغيل ترجمان بعد أي تغيير. والمتغير المضبوط في البيئة الفعلية يتقدّم على ما في الملف.

| متغير البيئة | القيمة الافتراضية | المعنى |
|---|---|---|
| `TARJUMAN_HOME` | مجلد المشروع | مكان حفظ `data/` |
| `TARJUMAN_PORT` | `4318` | أول منفذ يُجرَّب (ينتقل إلى المنفذ التالي إذا كان مشغولًا، والإضافة تتبعه) |
| `TARJUMAN_HOST` | `0.0.0.0` | استخدم `127.0.0.1` لإبقاء التطبيق خارج شبكة Wi-Fi |
| `TARJUMAN_WHISPER_MODEL` | `base` | `small` أو `medium` لتفريغ صوتي أدق (وأبطأ) |
| `TARJUMAN_VOICE_CACHE_GB` | `2` | حدّ حجم أصوات الدبلجة المحفوظة؛ يُحذف الأقدم استخدامًا أولًا |
| `TARJUMAN_MAX_UPLOAD_GB` | `8` | أكبر حجم لفيديو يمكنك رفعه |
| `TARJUMAN_PAIR_MINUTES` | `15` | مدة صلاحية رمز اقتران الهاتف (رمز QR)؛ `0` = حتى تُنشئ رمزًا جديدًا |
| `TARJUMAN_FETCH_PRIVATE` | معطّل | اضبطه على `1` للسماح بالتنزيل من عناوين داخل شبكتك أنت |
| `TARJUMAN_HEAVY_JOBS` | `2` | عدد المهام الثقيلة (Whisper، والدبلجة، ودمج الترجمة في الصورة) التي تعمل معًا؛ استخدم `1` على جهاز قليل الذاكرة |
| `TARJUMAN_MAX_QUEUE` | `20` | أقصى عدد من المهام التي يمكن أن تنتظر دورها |
| `TARJUMAN_FORCE_ASR` | معطّل | اضبطه على `1` لتفريغ الصوت دائمًا بـ Whisper، مع تجاهل ترجمات YouTube |
| `ANTHROPIC_API_KEY` | – | يُستخدم مع Claude إذا لم يُحفظ مفتاح في الإعدادات |

## بنية المشروع

```
backend/     Python package `tarjuman` (FastAPI): captions, translation, voices, dubbing, AI, jobs
frontend/    Vue 3 + Vite + TypeScript web app
extension/   Chrome / Edge extension (Manifest V3, Vue + Vite) and its store kit
shared/      the live dub engine used by both the web app and the extension
assets/      brand (icon source and renders)
docs/        plan, specification, implementation notes, translated READMEs, screenshots
```

## التطوير

```sh
# backend tests (offline)
cd backend && ../.venv/bin/python -m pytest      # Windows: ..\.venv\Scripts\python

# dub engine tests
npm test

# web app with hot reload (proxies the API to 127.0.0.1:4318)
npm --prefix frontend run dev

# extension: build, test, package a store zip
npm --prefix extension run build && npm --prefix extension test && npm --prefix extension run package
```

اقرأ [docs/specs.md](../specs.md) قبل تغيير أي مسار في الـ API، فتطبيق الويب والإضافة كلاهما يعتمدان عليه.

```powershell
powershell -ExecutionPolicy Bypass -File installer\build.ps1   # build\windows\app: Python, packages, web app, extension

```
