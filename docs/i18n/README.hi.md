## यह क्या करता है

YouTube लिंक पेस्ट करें, अपने कंप्यूटर से वीडियो अपलोड करें, या लगभग किसी भी साइट का लिंक दें।

- **सिंक सबटाइटल।** अरबी सबटाइटल वीडियो पर लाइन-दर-लाइन दिखते हैं, और चाहें तो नीचे मूल भाषा भी। अपने-आप बने कैप्शन अनुवाद से पहले पूरे वाक्यों में जोड़ दिए जाते हैं।
- **इंसान जैसी आवाज़ वाली लाइव डबिंग।** एक न्यूरल अरबी आवाज़ हर वाक्य को वक्ता के साथ-साथ बोलती है — मिस्री, सऊदी, अमीराती, सीरियाई, जॉर्डनियन, लेबनानी, मोरक्कन या इराकी अरबी में। कोई वाक्य न कटता है, न छूटता है, और वीडियो तभी रुकता है जब डब काफ़ी पीछे रह जाए।
- **डब किया हुआ MP4।** वीडियो को अरबी वॉइस-ओवर के साथ एक्सपोर्ट करें। यह संगीत और इफ़ेक्ट्स रखते हुए मूल वक्ता की आवाज़ हटा सकता है, हर वक्ता को मेल खाती पुरुष या महिला आवाज़ दे सकता है, और सबटाइटल एम्बेड या वीडियो में बर्न कर सकता है।
- **कैप्शन नहीं हैं? कोई बात नहीं।** Whisper आपके कंप्यूटर पर ऑडियो को टेक्स्ट में बदलता है, फिर उस ट्रांसक्रिप्ट का अनुवाद होता है।
- **सबटाइटल फ़ाइलें।** SRT, VTT या सादा टेक्स्ट डाउनलोड करें, अरबी में या द्विभाषी, या शेयर करने के लिए तैयार सबटाइटल वाला MP4।
- **पूरी प्लेलिस्ट।** किसी प्लेलिस्ट या चैनल का लिंक दें, और यह उसके हर वीडियो के लिए सबटाइटल, सबटाइटल वाले वीडियो या डब किए गए वीडियो बना देगा।
- **वीडियो से पूछें** (वैकल्पिक AI)। सारांश, मुख्य बिंदु, क्लिक करने योग्य अध्याय, और ऐसे जवाब पाएँ जो सीधे उस पल पर ले जाते हैं जहाँ वीडियो आपके सवाल की बात करता है। Claude या किसी भी OpenAI-संगत प्रदाता (Gemini, Groq, OpenRouter, Ollama) के साथ काम करता है।
- **अंग्रेज़ी सीखें।** किसी भी शब्द पर टैप करके उसका अर्थ देखें, उसे उसके वाक्य के साथ सेव करें, बाद में दोहराएँ, और Anki में एक्सपोर्ट करें। आप कोई वाक्य दोहरा भी सकते हैं, हर लाइन के बाद रोक सकते हैं, या खुद को परखने के लिए सबटाइटल धुंधले कर सकते हैं।
- **ब्राउज़र एक्सटेंशन।** यही सबटाइटल और डबिंग सीधे YouTube पर, उन साइटों पर जिनके प्लेयर में कैप्शन हैं (Coursera, Udemy और अन्य), या टैब का ऑडियो सुनकर किसी भी दूसरी साइट पर इस्तेमाल करें।

दूसरी भाषाएँ भी चलती हैं: फ़्रेंच, स्पैनिश, जर्मन, तुर्की और अंग्रेज़ी लक्ष्य भाषाओं के रूप में पहले से शामिल हैं।

## जल्दी शुरू करें

आपको **Python 3.11+** और **Node.js 20+** चाहिए।

**Windows:** `start.cmd` पर डबल-क्लिक करें।

**macOS / Linux:**

```sh
./start.sh
```

पहली बार चलाने पर सब कुछ इंस्टॉल हो जाता है: Python पैकेज, ऑफ़लाइन अरबी आवाज़, और वेब ऐप का बिल्ड। फिर ऐप `http://127.0.0.1:4318` पर खुलता है। बाद में यह कुछ ही सेकंड में शुरू हो जाता है। फ़ोन से इस्तेमाल करने के लिए वह पता खोलें जो यह आपके Wi-Fi के लिए दिखाता है।

<details>
<summary>मैन्युअल सेटअप</summary>

```sh
python -m venv .venv
.venv/bin/pip install -r backend/requirements.txt        # Windows: .venv\Scripts\pip
npm --prefix frontend install && npm --prefix frontend run build
PYTHONPATH=backend .venv/bin/python -m tarjuman           # Windows: set PYTHONPATH=backend
```

### कमांड

| कमांड | क्या करती है |
|---|---|
| `python -m tarjuman` | ऐप शुरू करती है (`--port`, सिर्फ़ इसी कंप्यूटर के लिए `--host 127.0.0.1`, `--no-open`) |
| `python -m tarjuman subs <link>` | सबटाइटल फ़ाइलें `data/output` में लिखती है (`--lang`, `--format srt,vtt,txt`) |
| `python -m tarjuman setup` | सब कुछ इंस्टॉल या ठीक करती है |
| `python -m tarjuman update` | डाउनलोड या आवाज़ें काम करना बंद कर दें तो yt-dlp और वॉइस क्लाइंट अपडेट करती है |
| `python -m tarjuman doctor` | हर कंपोनेंट की जाँच करती है |

## ब्राउज़र एक्सटेंशन

<p align="center">
  <img src="../screenshots/extension-popup.png" alt="Tarjuman एक्सटेंशन का पॉपअप" width="320">
</p>

1. इसे एक बार बिल्ड करें: `npm --prefix extension install && npm --prefix extension run build`।
2. `chrome://extensions` (या `edge://extensions`) खोलें, **डेवलपर मोड** चालू करें, **अनपैक्ड लोड करें** पर क्लिक करें, और `extension/dist` चुनें।
3. ऐप चलता रहने दें, कोई वीडियो खोलें, और Tarjuman आइकन पर क्लिक करें, या <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> दबाएँ।

एक्सटेंशन सिर्फ़ आपके कंप्यूटर पर चल रहे ऐप से बात करता है। इसकी Chrome Web Store किट (लिस्टिंग टेक्स्ट, अनुमतियों का औचित्य, प्राइवेसी पॉलिसी, प्रचार चित्र) [`extension/store`](../../extension/store) में है।

## डब सिंक में कैसे रहता है

कैप्शन की लाइनों को पूरे वाक्यों में जोड़ा जाता है और भराव वाले शब्द हटा दिए जाते हैं। फिर हर वाक्य की गति लगभग 12 सेकंड की आगे देखने वाली विंडो के आधार पर चुनी जाती है, ताकि खुला-खुला वाक्य भीड़ वाले वाक्य को समय उधार दे सके और गति अचानक उछलने के बजाय धीरे-धीरे बदले। ब्राउज़र के कुछ भी चलाने से पहले सर्वर हर वाक्य को सिंथेसाइज़ करके उसकी अवधि मापता है, इसलिए योजना अंदाज़ों पर नहीं बल्कि असली अवधियों पर आधारित होती है। अगर फिर भी डब पीछे रह जाए, तो अगले वाक्य थोड़ा तेज़ चलते हैं; वीडियो तभी रुकता है जब अंतर लगभग दो सेकंड से ज़्यादा हो जाए। कहीं भी सीक करें, डब ठीक उसी जगह से फिर शुरू होता है।

पूरा डिज़ाइन [docs/implementation.md](../implementation.md) में है।

## गोपनीयता

Tarjuman लोकल-फ़र्स्ट है। आपके वीडियो, सबटाइटल, सेव किए गए शब्द, सेटिंग्स और API कुंजी आपके कंप्यूटर पर `data/` फ़ोल्डर में रहते हैं। ऐप YouTube (कैप्शन और डाउनलोड), Google Translate और MyMemory (अनुवाद), Microsoft की Edge वॉइस सेवा (आवाज़) से, और सिर्फ़ आपके चालू करने पर आपके चुने हुए AI प्रदाता से संपर्क करता है। न कोई अकाउंट, न एनालिटिक्स, न ट्रैकिंग। API दूसरी वेबसाइटों के अनुरोध ठुकरा देता है, और AI सेटिंग्स सिर्फ़ उसी कंप्यूटर से बदली जा सकती हैं जिस पर ऐप चल रहा है।

## कॉन्फ़िगरेशन

| एनवायरनमेंट वेरिएबल | डिफ़ॉल्ट | अर्थ |
|---|---|---|
| `TARJUMAN_HOME` | प्रोजेक्ट फ़ोल्डर | जहाँ `data/` रखा जाता है |
| `TARJUMAN_PORT` | `4318` | आज़माया जाने वाला पहला पोर्ट (व्यस्त हो तो अगला लेता है; एक्सटेंशन भी साथ चलता है) |
| `TARJUMAN_HOST` | `0.0.0.0` | ऐप को अपने Wi-Fi से दूर रखने के लिए `127.0.0.1` इस्तेमाल करें |
| `TARJUMAN_WHISPER_MODEL` | `base` | ज़्यादा सटीक (पर धीमे) ट्रांसक्रिप्शन के लिए `small` या `medium` |
| `ANTHROPIC_API_KEY` | – | सेटिंग्स में कोई कुंजी सेव न हो तो Claude के लिए इस्तेमाल होती है |

## प्रोजेक्ट की संरचना

```
backend/     Python package `tarjuman` (FastAPI): captions, translation, voices, dubbing, AI, jobs
frontend/    Vue 3 + Vite + TypeScript web app
extension/   Chrome / Edge extension (Manifest V3, Vue + Vite) and its store kit
shared/      the live dub engine used by both the web app and the extension
assets/      brand (icon source and renders)
docs/        plan, specification, implementation notes, translated READMEs, screenshots
```

## डेवलपमेंट

```sh
# backend tests (offline)
cd backend && ../.venv/bin/python -m pytest      # Windows: ...venvScriptspython

# dub engine tests
npm test

# web app with hot reload (proxies the API to 127.0.0.1:4318)
npm --prefix frontend run dev

# extension: build, test, package a store zip
npm --prefix extension run build && npm --prefix extension test && npm --prefix extension run package
```

किसी API रूट को बदलने से पहले [docs/specs.md](../specs.md) पढ़ें: वेब ऐप और एक्सटेंशन दोनों उसी पर निर्भर हैं।
