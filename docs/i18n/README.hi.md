## यह क्या करता है

YouTube लिंक पेस्ट करें, अपने कंप्यूटर से कोई वीडियो या ऑडियो फ़ाइल अपलोड करें, अपनी आवाज़ रिकॉर्ड करें, या लगभग किसी भी साइट का लिंक दें।

- **सिंक सबटाइटल।** अरबी सबटाइटल वीडियो पर लाइन-दर-लाइन दिखते हैं, और चाहें तो नीचे मूल भाषा भी। अपने-आप बने कैप्शन अनुवाद से पहले पूरे वाक्यों में जोड़ दिए जाते हैं। अगर उनमें विराम-चिह्न बिल्कुल न हों, तो YouTube की हर शब्द की टाइमिंग के सहारे उन्हें वहीं तोड़ा जाता है जहाँ वक्ता सचमुच रुकता है।
- **इंसान जैसी आवाज़ वाली लाइव डबिंग।** एक न्यूरल अरबी आवाज़ हर वाक्य को वक्ता के साथ-साथ बोलती है — मिस्री, सऊदी, अमीराती, सीरियाई, जॉर्डनियन, लेबनानी, मोरक्कन या इराकी अरबी में। कोई वाक्य न कटता है, न छूटता है। तेज़ बोलने वाले वक्ता के साथ आवाज़ को दौड़ाने के बजाय वीडियो थोड़ा धीमा हो जाता है, ताकि आवाज़ बराबरी पर आ जाए; आप ख़ुद वीडियो धीमा करें, तो वह अतिरिक्त समय आवाज़ को मिलता है। जो शब्द लिखे एक जैसे जाते हैं पर पढ़े अलग ढंग से, उन्हें वाक्य के अर्थ के अनुसार पढ़ा जाता है (الجُمَل यानी "वाक्य", न कि الجَمَل यानी "ऊँट"), और यह अंग्रेज़ी मूल से तय होता है।
- **डब किया हुआ MP4।** वीडियो को अरबी वॉइस-ओवर के साथ एक्सपोर्ट करें। यह संगीत और इफ़ेक्ट्स रखते हुए मूल वक्ता की आवाज़ हटा सकता है, हर वक्ता को मेल खाती पुरुष या महिला आवाज़ दे सकता है, और सबटाइटल एम्बेड या वीडियो में बर्न कर सकता है।
- **कैप्शन नहीं हैं? कोई बात नहीं।** Whisper आपके कंप्यूटर पर ऑडियो को टेक्स्ट में बदलता है, फिर उस ट्रांसक्रिप्ट का अनुवाद होता है। सेटिंग्स → ट्रांसक्रिप्शन आपके कंप्यूटर (मेमोरी, ग्राफ़िक्स कार्ड, प्रोसेसर) को जाँचकर एक मॉडल सुझाता है और बताता है कि क्यों, और रिकॉर्डिंग, वीडियो और लाइव सुनने के लिए अलग-अलग मॉडल चुनने देता है। अरबी बोली के लिए बोलियों (मिस्री, खाड़ी, शामी और अन्य) पर प्रशिक्षित एक मॉडल है, जिसने एक मिस्री वॉइस नोट पर हमारे परीक्षण में मानक मॉडलों की तुलना में कहीं कम शब्द ग़लत किए। आप उन शब्दों की सूची जोड़ सकते हैं जिन्हें इसे सही पहचानना चाहिए (नाम, उत्पाद, अरबी में बोले गए अंग्रेज़ी शब्द), साथ में यह भी कि हर शब्द कैसे लिखा जाए, और चाहें तो बाद में अपने AI प्रदाता से ट्रांसक्रिप्ट सुधरवा सकते हैं। CTranslate2 फ़ॉर्मेट का कोई भी Whisper मॉडल Hugging Face से या आपके कंप्यूटर के किसी फ़ोल्डर से जोड़ा जा सकता है, और डाउनलोड किए गए मॉडल जगह खाली करने के लिए हटाए जा सकते हैं।
- **ऑडियो फ़ाइलें और वॉइस नोट।** MP3, M4A, WAV, OGG, Opus, FLAC या WhatsApp वॉइस नोट अपलोड करें, या सीधे अपने माइक्रोफ़ोन से रिकॉर्ड करें। ख़ाली वीडियो की जगह इसे एक चलती हुई वेवफ़ॉर्म मिलती है, साथ में सिंक ट्रांसक्रिप्ट, और इसे सबटाइटल, डब किए गए M4A, या शेयर करने के लिए वेवफ़ॉर्म और बर्न किए गए सबटाइटल वाले वीडियो के रूप में एक्सपोर्ट किया जा सकता है।
- **सबटाइटल फ़ाइलें।** SRT, VTT या सादा टेक्स्ट डाउनलोड करें, अरबी में या द्विभाषी, या शेयर करने के लिए तैयार सबटाइटल वाला MP4।
- **पूरी प्लेलिस्ट।** किसी प्लेलिस्ट या चैनल का लिंक दें, और यह उसके हर वीडियो के लिए सबटाइटल, सबटाइटल वाले वीडियो या डब किए गए वीडियो बना देगा।
- **वीडियो से पूछें** (वैकल्पिक AI)। सारांश, मुख्य बिंदु, क्लिक करने योग्य अध्याय, और ऐसे जवाब पाएँ जो सीधे उस पल पर ले जाते हैं जहाँ वीडियो आपके सवाल की बात करता है। Claude या किसी भी OpenAI-संगत प्रदाता (Gemini, Groq, OpenRouter, Ollama) के साथ काम करता है।
- **आपके नियंत्रण वाला देखने का पेज।** वीडियो के बगल में ट्रांसक्रिप्ट हर शब्द को बोले जाते ही हाइलाइट करता है, वक्ता के बदलने और [music] जैसी आवाज़ों को चिह्नित करता है, और उसमें खोजा जा सकता है; किसी भी लाइन पर क्लिक करके वहाँ पहुँचें। वीडियो के मालिक के अध्याय (या AI सारांश के अध्याय) ट्रांसक्रिप्ट में अपने हिस्से के शीर्षक बनते हैं और टाइमलाइन पर चिह्नित होते हैं। वीडियो के नीचे एक टाइमलाइन दिखाती है कि लाइनें कहाँ हैं, प्लेयर के पीछे वीडियो के अपने रंगों की हल्की रोशनी चमकती है, और सिनेमा मोड (<kbd>T</kbd>) बाकी सब कुछ धुंधला कर देता है। इनमें से हर एक को सेटिंग्स → देखना में बंद या समायोजित किया जा सकता है। कीबोर्ड: <kbd>→</kbd> अगली लाइन, <kbd>←</kbd> पिछली लाइन, <kbd>R</kbd> दोहराएँ, <kbd>K</kbd> चलाएँ या रोकें, <kbd>?</kbd> पूरी सूची के लिए (ये अरबी कीबोर्ड लेआउट के साथ भी काम करते हैं)।
- **अंग्रेज़ी सीखें।** किसी भी शब्द पर टैप करके उसका अर्थ देखें, उसे उसके वाक्य के साथ सेव करें, बाद में दोहराएँ, और Anki में एक्सपोर्ट करें। आप कोई वाक्य दोहरा भी सकते हैं, हर लाइन के बाद रोक सकते हैं, या खुद को परखने के लिए सबटाइटल धुंधले कर सकते हैं।
- **ब्राउज़र एक्सटेंशन।** यही सबटाइटल और डबिंग सीधे YouTube पर, दूसरी साइटों में एम्बेड किए गए YouTube वीडियो पर, उन साइटों पर जिनके प्लेयर में कैप्शन हैं (Coursera, Udemy और अन्य), फ़िल्म और ऐनिमे की उन साइटों पर जो अपना प्लेयर किसी दूसरी साइट से एम्बेड करती हैं, या टैब का ऑडियो सुनकर किसी भी दूसरी साइट पर इस्तेमाल करें। YouTube पर यह वीडियो के बगल में ट्रांसक्रिप्ट, क्लिक किए गए किसी भी शब्द का अर्थ, लाइन-दर-लाइन शॉर्टकट, और ऐप में आगे देखने का एक बटन जोड़ता है।
- **अपने फ़ोन पर।** उसी Wi-Fi से जुड़े किसी भी फ़ोन से ऐप खोलें।

**74 भाषाओं** में अनुवाद और डबिंग की जा सकती है, हर एक में देशी आवाज़ों के साथ (जापानी जापानी जैसी लगती है, हिंदी हिंदी जैसी), और यह सब बिना इंटरनेट के भी चल सकता है:

- **ऑफ़लाइन अनुवाद:** किसी भाषा का मॉडल एक बार डाउनलोड करें (सेटिंग्स → ऑफ़लाइन अनुवाद), और अनुवाद आपके कंप्यूटर पर चलता है, जब Google उपलब्ध न हो तब या हमेशा।
- 31 भाषाओं में **ऑफ़लाइन आवाज़ें**, जो एक साधारण लैपटॉप पर लाइव डबिंग करती हैं।
- **वॉइस पैक**, जो सिर्फ़ आपके चाहने पर इंस्टॉल होते हैं: किसी MP4 को **मूल वक्ता की अपनी आवाज़** में डब करें (प्रायोगिक), या सक्षम ग्राफ़िक्स कार्ड वाले कंप्यूटर पर **अरबी बोलियों की आवाज़ों** (मिस्री, इराकी, मोरक्कन…) में।

## जल्दी शुरू करें

### Windows इंस्टॉलर

[Releases](https://github.com/MohamedElnagar94/tarjuman/releases) पेज से `Tarjuman-Setup-<version>.exe` डाउनलोड करें और चलाएँ। यह अपना Python, सारे पैकेज, वेब ऐप और ब्राउज़र एक्सटेंशन साथ लाता है, इसलिए आपको न Python चाहिए, न Node.js। यह एक बार एडमिनिस्ट्रेटर अधिकार माँगता है, Program Files में इंस्टॉल होता है, और फ़ायरवॉल को नहीं छूता। इसके बाद Tarjuman किसी भी डेस्कटॉप ऐप की तरह अपनी अलग विंडो में खुलता है, न कोई कंसोल विंडो, न ब्राउज़र टैब। डिफ़ॉल्ट रूप से विंडो बंद करने पर यह रुक जाता है; सेटिंग्स → डेस्कटॉप में इसके बजाय इसे नोटिफ़िकेशन एरिया में रखा जा सकता है, ब्राउज़र एक्सटेंशन के लिए इंजन चालू रखा जा सकता है, और इसे Windows के साथ शुरू किया जा सकता है। (यह विंडो ऐप मोड में Microsoft Edge है, जो हर Windows 10 और 11 में होता है; कुछ भी अतिरिक्त इंस्टॉल नहीं होता।)

- अगर Setup तुरंत "unable to create the directory ...\Temp\is-*.tmp, access is denied" कहकर रुक जाए, तो इंस्टॉलर फ़ाइल ऐसे फ़ोल्डर में है जिसे लो-इंटेग्रिटी चिह्नित किया गया है (कुछ सैंडबॉक्सिंग टूल अपने वर्किंग फ़ोल्डर इसी तरह चिह्नित करते हैं; तब `icacls <file>` में `Low Mandatory Level` दिखता है)। Windows ऐसी फ़ाइल को कम अधिकारों के साथ चलाता है। उसे किसी दूसरे फ़ोल्डर, जैसे Downloads, में कॉपी करें और कॉपी को चलाएँ।
- इंस्टॉलर अभी कोड-साइन नहीं है, इसलिए Windows SmartScreen "अज्ञात प्रकाशक" कह सकता है: *More info → Run anyway* (अधिक जानकारी → फिर भी चलाएँ) चुनें।
- पहली बार शुरू होने पर ऑफ़लाइन अरबी आवाज़ (लगभग 60 MB) बैकग्राउंड में डाउनलोड होती है। Whisper मॉडल तब अपने-आप डाउनलोड होता है जब किसी वीडियो को पहली बार उसकी ज़रूरत पड़ती है।
- अपडेट: सेटिंग्स → अपडेट दिखाता है कि नया संस्करण क्या जोड़ता और ठीक करता है, और उसे एक क्लिक में इंस्टॉल करता है (या अपने-आप, अगर आप वह विकल्प चालू करें)।
- आपके वीडियो, सबटाइटल, सेटिंग्स और `.env` प्रोग्राम से अलग, `%LOCALAPPDATA%\Tarjuman` में रखे जाते हैं। अपडेट उन्हें बनाए रखता है; अनइंस्टॉल करते समय पूछा जाता है कि उन्हें हटाना है या नहीं।
- Start मेनू में एक्सटेंशन फ़ोल्डर का शॉर्टकट है, `chrome://extensions` में *अनपैक्ड लोड करें* के लिए।

कुछ काम नहीं कर रहा? [समस्या निवारण](../troubleshooting.md) देखें। हर संस्करण में क्या बदला, यह [Changelog](../../CHANGELOG.md) में है।

### Linux (AppImage)

[Releases](https://github.com/MohamedElnagar94/tarjuman/releases) पेज से `Tarjuman-<version>-x86_64.AppImage` डाउनलोड करें, उसे एक्ज़ीक्यूटेबल बनाएँ, और चलाएँ। Windows इंस्टॉलर की तरह यह अपना Python, सारे पैकेज, वेब ऐप और एक्सटेंशन साथ लाता है।

```sh
chmod +x Tarjuman-*-x86_64.AppImage
./Tarjuman-*-x86_64.AppImage
```

- अगर Chrome, Chromium या Edge इंस्टॉल है तो यह अपनी अलग विंडो में खुलता है, वरना आपके डिफ़ॉल्ट ब्राउज़र में (तब यह तब तक चलता रहता है जब तक आप लॉग आउट न करें, या `pkill -f "tarjuman app"` न चलाएँ)।
- आपका डेटा `~/.local/share/Tarjuman` में रखा जाता है। सेटिंग्स → अपडेट नए AppImage की जाँच करने के बाद पुराने को उससे बदल देता है; उसे इस्तेमाल करने के लिए Tarjuman को फिर से शुरू करें।
- अगर यह कहे कि FUSE मौजूद नहीं है (कुछ डिस्ट्रीब्यूशन और WSL पर), तो इसे `--appimage-extract-and-run` के साथ चलाएँ, या `libfuse2` इंस्टॉल करें।
- नोटिफ़िकेशन एरिया का आइकन और डेस्कटॉप सेटिंग्स फ़िलहाल सिर्फ़ Windows के लिए हैं।

### सोर्स कोड से

आपको **Python 3.11+** और **Node.js 20+** चाहिए।

**Windows:** `start.cmd` पर डबल-क्लिक करें। अगर Windows पूछे कि किसी अज्ञात प्रकाशक की स्क्रिप्ट चलानी है या नहीं, तो एक बार `powershell -ExecutionPolicy Bypass -File scripts/create-shortcut.ps1` से डेस्कटॉप शॉर्टकट बना लें और Tarjuman को उसी से शुरू करें; यह वही स्क्रिप्ट Windows के अपने `cmd.exe` से चलाता है, इसलिए यह सवाल नहीं आता।

**macOS / Linux:**

```sh
./start.sh
```

Debian, Ubuntu और Kali पर, अगर `python3-venv` न हो तो पहले उसे इंस्टॉल करें (`sudo apt install python3-venv`)।

पहली बार चलाने पर सब कुछ इंस्टॉल हो जाता है: Python पैकेज, ऑफ़लाइन अरबी आवाज़, और वेब ऐप का बिल्ड। फिर ऐप `http://127.0.0.1:4318` पर खुलता है। बाद में यह कुछ ही सेकंड में शुरू हो जाता है। फ़ोन से इस्तेमाल करने के लिए वह पता खोलें जो यह आपके Wi-Fi के लिए दिखाता है। Windows पर अगर फ़ोन उस तक न पहुँच पाए, तो एक बार एडमिनिस्ट्रेटर के रूप में `scripts/allow-phone.ps1` चलाएँ: यह आपके घर के Wi-Fi को Private चिह्नित करता है और Tarjuman के पोर्ट सिर्फ़ Private नेटवर्क पर खोलता है।

<summary>मैन्युअल सेटअप</summary>

```sh
python -m venv .venv
.venv/bin/pip install -r backend/requirements.txt        # Windows: .venv\Scripts\pip
npm --prefix frontend install && npm --prefix frontend run build
PYTHONPATH=backend .venv/bin/python -m tarjuman           # Windows: set PYTHONPATH=backend
```

### कमांड

| कमांड | क्या करती है |
|---|---|
| `python -m tarjuman` | ऐप शुरू करती है (`--port`, सिर्फ़ इसी कंप्यूटर के लिए `--host 127.0.0.1`, `--no-open`) |
| `python -m tarjuman app` | ऐप को ब्राउज़र टैब के बजाय उसकी अपनी विंडो में शुरू करती है (ऐप मोड में Edge या Chrome); Windows पर नोटिफ़िकेशन एरिया आइकन के साथ (`--background` इसे बिना विंडो के वहीं शुरू करता है) |
| `python -m tarjuman subs <link>` | सबटाइटल फ़ाइलें `data/output` में लिखती है (`--lang`, `--format srt,vtt,txt`) |
| `python -m tarjuman setup` | सब कुछ इंस्टॉल या ठीक करती है |
| `python -m tarjuman update` | डाउनलोड या आवाज़ें काम करना बंद कर दें तो yt-dlp और वॉइस क्लाइंट अपडेट करती है |
| `python -m tarjuman doctor` | हर कंपोनेंट की जाँच करती है |

## ब्राउज़र एक्सटेंशन

<p align="center">
  <img src="../screenshots/extension-popup.png" alt="Tarjuman एक्सटेंशन का पॉपअप" width="320">
</p>

इसे सीधे [Chrome Web Store](https://chromewebstore.google.com/detail/gcfnomfbpenbhdebopmpdfamlaiodflp) से इंस्टॉल करें, या नीचे दिए चरणों से सोर्स से बनाएँ:

1. इसे एक बार बिल्ड करें: `npm --prefix extension install && npm --prefix extension run build`।
2. `chrome://extensions` (या `edge://extensions`) खोलें, **डेवलपर मोड** चालू करें, **अनपैक्ड लोड करें** पर क्लिक करें, और `extension/dist` चुनें।
3. ऐप चलता रहने दें, कोई वीडियो खोलें, और Tarjuman आइकन पर क्लिक करें, या <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> दबाएँ।
4. इसके विकल्प पेज पर सबटाइटल का फ़ॉन्ट, एक्सटेंशन की भाषा (ब्राउज़र वाली, अरबी या अंग्रेज़ी), कीबोर्ड शॉर्टकट, और यह सेट होता है कि YouTube पर यह अपने-आप शुरू हो या नहीं (कभी नहीं, हमेशा, या सिर्फ़ आपके चुने हुए चैनलों पर)।

अगर Chrome *Proceed with caution: this extension is not trusted by Enhanced Safe Browsing* दिखाए, तो इसका कारण यह है कि प्रकाशक Chrome Web Store पर नया है: Chrome यह हर नए प्रकाशक के लिए तब तक दिखाता है जब तक वह कुछ महीनों तक स्टोर की नीतियों का पालन न कर ले, और केवल उन्हें जिन्होंने उन्नत सुरक्षा चालू की है। एक्सटेंशन ने स्टोर की समीक्षा पास की है, और इसका [सोर्स कोड](https://github.com/MohamedElnagar94/tarjuman/tree/main/extension) खुला है। *Continue to install* चुनें।

अनुवाद करते समय:

- YouTube पर **वीडियो के बगल में ट्रांसक्रिप्ट**: हर लाइन, मौजूदा लाइन हाइलाइट; किसी लाइन पर क्लिक करके वहाँ पहुँचें, या खोजें।
- मूल लाइन में **किसी शब्द पर क्लिक करें** और उसका अर्थ देखें, और उसे उसके वाक्य के साथ ऐप में *मेरे शब्द* में सेव करें।
- **शॉर्टकट:** <kbd>Alt</kbd>+<kbd>→</kbd> अगली लाइन, <kbd>Alt</kbd>+<kbd>←</kbd> पिछली लाइन, <kbd>Alt</kbd>+<kbd>↓</kbd> दोहराएँ, <kbd>Alt</kbd>+<kbd>S</kbd> सबटाइटल, <kbd>Alt</kbd>+<kbd>V</kbd> डबिंग, <kbd>Alt</kbd>+<kbd>T</kbd> ट्रांसक्रिप्ट।
- **टाइमिंग:** अगर लाइनें बोलने से पहले या बाद में आएँ, तो उन्हें <kbd>Alt</kbd>+<kbd>[</kbd> और <kbd>Alt</kbd>+<kbd>]</kbd> से खिसकाएँ (डब भी उनके साथ खिसकता है)।
- उसी पल पर **ऐप में खोलें**, एक्सपोर्ट और पूरे देखने के पेज के लिए।
- यह YouTube के मिनीप्लेयर में भी काम करता रहता है, कोर्स साइट पर अगले पाठ तक साथ चलता है, और जब कोई साइट सिर्फ़ वीडियो को फ़ुल स्क्रीन करती है तब भी लाइन दिखाता है।

एक्सटेंशन सिर्फ़ आपके कंप्यूटर पर चल रहे ऐप से बात करता है। इसकी Chrome Web Store किट (लिस्टिंग टेक्स्ट, अनुमतियों का औचित्य, प्राइवेसी पॉलिसी, प्रचार चित्र) [`extension/store`](../../extension/store) में है।

## डब सिंक में कैसे रहता है

कैप्शन की लाइनों को पूरे वाक्यों में जोड़ा जाता है और भराव वाले शब्द हटा दिए जाते हैं। फिर हर वाक्य की गति लगभग 12 सेकंड की आगे देखने वाली विंडो के आधार पर चुनी जाती है, ताकि खुला-खुला वाक्य भीड़ वाले वाक्य को समय उधार दे सके और गति अचानक उछलने के बजाय धीरे-धीरे बदले। ब्राउज़र के हर हिस्से के पहले वाक्य चलाने से पहले सर्वर उन्हें सिंथेसाइज़ करके उनकी अवधि मापता है, इसलिए योजना अंदाज़ों पर नहीं बल्कि असली अवधियों पर आधारित होती है, और अगला हिस्सा वह बैकग्राउंड में तैयार करता है। अगर फिर भी डब पीछे रह जाए, तो आवाज़ के बराबरी पर आने तक वीडियो आपकी गति के 85% पर धीमा हो जाता है, और तभी रुकता है जब अंतर लगभग दो सेकंड से ज़्यादा हो जाए। गति आपकी प्लेबैक स्पीड के हिसाब से चलती है। कहीं भी सीक करें, डब ठीक उसी जगह से फिर शुरू होता है। जब मुफ़्त अनुवादक अनुरोधों की सीमा लगा देते हैं, तो Google का एक दूसरा एंडपॉइंट और फिर YouTube का अपना अनुवाद डब को चालू रखते हैं।

पूरा डिज़ाइन [docs/implementation.md](../implementation.md) में है।

## गोपनीयता

Tarjuman लोकल-फ़र्स्ट है। आपके वीडियो, सबटाइटल, सेव किए गए शब्द, सेटिंग्स और API कुंजी आपके कंप्यूटर पर `data/` फ़ोल्डर में रहते हैं। ऐप YouTube (कैप्शन और डाउनलोड), Google Translate और MyMemory (अनुवाद), Microsoft की Edge वॉइस सेवा (आवाज़) से, और सिर्फ़ आपके चालू करने पर आपके चुने हुए AI प्रदाता से संपर्क करता है। न कोई अकाउंट, न एनालिटिक्स, न ट्रैकिंग। वीडियो और ऑडियो कभी अपलोड नहीं किए जाते।

| फ़ीचर | आपके कंप्यूटर से क्या बाहर जाता है | किसे भेजा जाता है | कुछ भी भेजे बिना |
|---|---|---|---|
| YouTube कैप्शन | वीडियो का लिंक | YouTube | फ़ाइल अपलोड करें; उसका ट्रांसक्रिप्शन लोकल होता है |
| अनुवाद | वीडियो के वाक्य, टेक्स्ट के रूप में | Google Translate, फिर MyMemory | ऑफ़लाइन अनुवाद मॉडल (सेटिंग्स → ऑफ़लाइन अनुवाद) |
| डबिंग की आवाज़ | हर अनूदित वाक्य और आवाज़ का नाम | Microsoft Edge की आवाज़ें, फिर Google | ऑफ़लाइन आवाज़ें (Supertonic, 31 भाषाएँ; अरबी के लिए Piper) और वॉइस पैक |
| वीडियो डाउनलोड | वीडियो के लिए एक अनुरोध | वह साइट जो उसे होस्ट करती है | आपके कंप्यूटर पर पहले से मौजूद फ़ाइल |
| AI (वैकल्पिक, डिफ़ॉल्ट रूप से बंद) | वीडियो का टेक्स्ट और आपका सवाल | आपका चुना हुआ प्रदाता | इसे बंद रहने दें, या Ollama जैसा लोकल सर्वर इस्तेमाल करें |
| मॉडल डाउनलोड | डाउनलोड का अनुरोध, एक बार | Hugging Face, GitHub, हेलसिंकी विश्वविद्यालय (अनुवाद मॉडल), PyTorch और PyPI (वॉइस पैक) | पहले डाउनलोड के बाद कुछ नहीं |
| अपडेट की जाँच | नए संस्करणों की सूची के लिए एक अनुरोध, हर कुछ घंटों में | GitHub | सेटिंग्स → अपडेट में "अपडेट अपने-आप जाँचें" बंद करें |
| ट्रांसक्रिप्ट सुधार (वैकल्पिक, डिफ़ॉल्ट रूप से बंद) | ट्रांसक्रिप्ट का टेक्स्ट | आपका चुना हुआ AI प्रदाता | इसे बंद रहने दें; शब्दों की सूची इसके बिना भी काम करती है |
| स्पीच रिकग्निशन, संगीत अलग करना, आपकी फ़ाइलें और रिकॉर्डिंग | कुछ नहीं | – | हमेशा लोकल |

यही तालिका ऐप में सेटिंग्स → गोपनीयता के अंतर्गत भी है। API दूसरी वेबसाइटों के अनुरोध ठुकरा देता है, और AI सेटिंग्स सिर्फ़ उसी कंप्यूटर से बदली जा सकती हैं जिस पर ऐप चल रहा है।

## कॉन्फ़िगरेशन

`.env.example` को प्रोजेक्ट फ़ोल्डर में `.env` नाम से कॉपी करें और उसे संपादित करें; हर सेटिंग वहीं अरबी और अंग्रेज़ी में समझाई गई है। यह फ़ाइल ऐप शुरू होते समय पढ़ी जाती है, इसलिए बदलाव के बाद Tarjuman को फिर से शुरू करें। असली एनवायरनमेंट में सेट किया गया वेरिएबल फ़ाइल से ऊपर माना जाता है।

| एनवायरनमेंट वेरिएबल | डिफ़ॉल्ट | अर्थ |
|---|---|---|
| `TARJUMAN_HOME` | प्रोजेक्ट फ़ोल्डर | जहाँ `data/` रखा जाता है |
| `TARJUMAN_PORT` | `4318` | आज़माया जाने वाला पहला पोर्ट (व्यस्त हो तो अगला लेता है; एक्सटेंशन भी साथ चलता है) |
| `TARJUMAN_HOST` | `0.0.0.0` | ऐप को अपने Wi-Fi से दूर रखने के लिए `127.0.0.1` इस्तेमाल करें |
| `TARJUMAN_WHISPER_MODEL` | (ख़ाली) | सेटिंग्स → ट्रांसक्रिप्शन में चुना जाता है, जो आपके कंप्यूटर के लिए एक मॉडल सुझाता है; जब तक वह सेटिंग स्वचालित पर है, यहाँ दिया गया मान इस्तेमाल होता है |
| `TARJUMAN_VOICE_CACHE_GB` | `2` | सहेजी गई डबिंग आवाज़ों की आकार-सीमा; सबसे पुरानी इस्तेमाल हुई पहले हटाई जाती हैं |
| `TARJUMAN_MAX_UPLOAD_GB` | `8` | सबसे बड़ा वीडियो जिसे आप अपलोड कर सकते हैं |
| `TARJUMAN_PAIR_MINUTES` | `15` | फ़ोन का पेयरिंग कोड (QR) कितनी देर चलता है; `0` = जब तक आप नया न बनाएँ |
| `TARJUMAN_FETCH_PRIVATE` | बंद | अपने ही नेटवर्क के भीतर के पतों से डाउनलोड की अनुमति देने के लिए `1` सेट करें |
| `TARJUMAN_HEAVY_JOBS` | `2` | कितने भारी जॉब (Whisper, डबिंग, सबटाइटल बर्न करना) एक साथ चलते हैं; कम मेमोरी वाले कंप्यूटर पर `1` रखें |
| `TARJUMAN_MAX_QUEUE` | `20` | अपनी बारी का इंतज़ार कर सकने वाले जॉब की अधिकतम संख्या |
| `TARJUMAN_FORCE_ASR` | बंद | YouTube के कैप्शन को नज़रअंदाज़ करके हमेशा Whisper से ट्रांसक्राइब करने के लिए `1` सेट करें |
| `ANTHROPIC_API_KEY` | – | सेटिंग्स में कोई कुंजी सेव न हो तो Claude के लिए इस्तेमाल होती है |

## प्रोजेक्ट की संरचना

```
backend/     Python package `tarjuman` (FastAPI): captions, translation, voices, dubbing, AI, jobs
frontend/    Vue 3 + Vite + TypeScript web app
extension/   Chrome / Edge extension (Manifest V3, Vue + Vite) and its store kit
shared/      the live dub engine used by both the web app and the extension
assets/      brand (icon source and renders)
docs/        plan, specification, implementation notes, translated READMEs, screenshots
```

## डेवलपमेंट

```sh
# backend tests (offline)
cd backend && ../.venv/bin/python -m pytest      # Windows: ..\.venv\Scripts\python

# dub engine tests
npm test

# web app with hot reload (proxies the API to 127.0.0.1:4318)
npm --prefix frontend run dev

# extension: build, test, package a store zip
npm --prefix extension run build && npm --prefix extension test && npm --prefix extension run package
```

किसी API रूट को बदलने से पहले [docs/specs.md](../specs.md) पढ़ें: वेब ऐप और एक्सटेंशन दोनों उसी पर निर्भर हैं।

### Windows इंस्टॉलर बनाना

```powershell
powershell -ExecutionPolicy Bypass -File installer\build.ps1   # build\windows\app: Python, packages, web app, extension
iscc /DAppVersion=3.0.0 installer\tarjuman.iss                # build\windows\Tarjuman-Setup-3.0.0.exe (Inno Setup 6)
```

*Windows installer* वर्कफ़्लो GitHub पर यही काम करता है: इसे Actions टैब से चलाएँ, या इंस्टॉलर को किसी रिलीज़ से जोड़ने के लिए `v3.0.0` जैसा टैग पुश करें। कंपाइल करने से पहले यह बंडल किए गए ऐप को शुरू करके जाँचता है कि वह जवाब देता है।

### Linux AppImage बनाना

```sh
installer/linux/build.sh   # build/linux/Tarjuman-<version>-x86_64.AppImage (needs curl, python3, Node.js 20+)
```

यह python-build-standalone से एक रीलोकेटेबल Python बंडल करता है। वही वर्कफ़्लो इसे Windows इंस्टॉलर के साथ बनाता है और `v*` टैग पर दोनों को प्रकाशित करता है।
